## 3. 주요 결정 사항

### 결정 1: 대시보드 Git 섹션 커밋 표시 건수
- **결정**: 최근 5건으로 제한
- **근거**: 화면 공간 제약 + 대부분의 사용자가 최근 변경에만 관심
- **향후**: 페이지네이션은 2차 스프린트에서 추가

### 결정 2: 회의 자동 스케줄링 알고리즘
- **결정**: 전원 가능한 시간대 중 가장 빠른 시간 우선 추천
- **근거**: 복잡한 최적화보다 단순 규칙이 사용자 이해에 용이
- **향후**: 선호도 가중치 도입은 피드백 이후 검토

### 결정 3: 알림 워크스페이스 라우팅
- **결정**: 다른 워크스페이스의 알림 클릭 시 전환 확인 팝업 표시
- **근거**: 사용자가 의도치 않게 워크스페이스가 바뀌는 것을 방지
- **담당**: 홍길동(디자인) → 김현수(백엔드 workspaceId 응답 추가)
