# DevBridge AX 인프라 및 운영 가이드

## 1. 시스템 아키텍처

```
[Vue 3 Frontend]  ←→  [Spring Boot Backend]  ←→  [FastAPI AI Engine]
     :3000                  :8080                      :8000
                               ↕                         ↕
                         [MySQL 8.0]              [Chroma Vector Store]
                            :3306                  (파일 기반, 임베디드)
                               ↕
                         [Redis Alpine]
                            :6379
```

### 서비스 구성
| 서비스 | 기술 스택 | 포트 | 역할 |
|--------|-----------|------|------|
| app | Spring Boot 4.0.6 / Java 25 | 8080 | REST API, 인증, 비즈니스 로직 |
| ai-engine | FastAPI / Python 3.12 | 8000 | RAG 질의응답, 문서 인덱싱, 커밋 분석 |
| mysql | MySQL 8.0 | 3306 | 관계형 데이터 저장 |
| redis | Redis Alpine | 6379 | 세션/토큰 캐싱 |

## 2. 로컬 개발 환경 구성

### 2.1 사전 요구사항
- Docker Desktop
- Java 25+
- Node.js 20+ (프론트엔드)
- Python 3.12+ (AI 엔진 로컬 개발 시)

### 2.2 최초 실행
```bash
# 1. MySQL + Redis 기동
docker compose up -d mysql redis

# 2. Spring Boot 로컬 실행
SPRING_DATASOURCE_DATABASE=devbridge SPRING_DATASOURCE_USERNAME=ssafy_be ./gradlew bootRun

# 또는 전체 Docker 실행
docker compose up -d
```

### 2.3 환경변수
| 변수 | 기본값 | 설명 |
|------|--------|------|
| SPRING_DATASOURCE_HOST | localhost | MySQL 호스트 |
| SPRING_DATASOURCE_PORT | 3306 | MySQL 포트 |
| SPRING_DATASOURCE_DATABASE | devbridge_ax | 데이터베이스명 |
| SPRING_DATASOURCE_USERNAME | ssafy | DB 사용자 |
| SPRING_DATASOURCE_PASSWORD | 1234 | DB 비밀번호 |
| SPRING_DATA_REDIS_HOST | localhost | Redis 호스트 |
| JWT_SECRET | (base64 인코딩) | JWT 서명 키 |
| INTERNAL_API_KEY | (빈 값) | 내부 API 인증 키 |
| FASTAPI_BASE_URL | http://localhost:8000 | AI 엔진 주소 |

## 3. 데이터베이스

### 3.1 초기화 흐름
```
Docker MySQL 최초 기동
  → init-db/init.sql 실행 (1회만)
    → CREATE DATABASE devbridge
    → CREATE USER ssafy_be (ALL PRIVILEGES + GRANT OPTION)
    → CREATE USER ssafy_ai (SELECT + DML)
    → CREATE TABLE document_chunks, usage_logs (AI 전용)

Spring Boot 기동
  → Hibernate ddl-auto: update (테이블 생성/수정)
  → data.sql 실행 (INSERT IGNORE — 시드 데이터)
```

### 3.2 계정 권한
| 계정 | 용도 | 권한 |
|------|------|------|
| ssafy_be | Spring Boot | ALL PRIVILEGES + GRANT OPTION |
| ssafy_ai | FastAPI AI Engine | SELECT + INSERT/UPDATE/DELETE (스키마 레벨) |

### 3.3 인코딩
- 서버: utf8mb4 + utf8mb4_unicode_ci
- 클라이언트 강제: `--skip-character-set-client-handshake`
- JDBC URL: `characterEncoding=UTF-8`

### 3.4 볼륨 초기화 (스키마 리셋 필요 시)
```bash
docker compose down
rm -rf .docker-data/mysql
docker compose up -d
# init.sql 재실행 → Hibernate DDL → data.sql 자동 적용
```

## 4. Docker Compose 서비스 관리

### 4.1 주요 명령어
```bash
# 전체 기동
docker compose up -d

# 특정 서비스만 기동
docker compose up -d mysql redis

# 앱 재빌드 (코드 변경 반영)
docker compose up -d --build app

# 로그 확인
docker compose logs -f app
docker compose logs -f ai-engine

# 전체 중지
docker compose down

# 상태 확인
docker compose ps
```

### 4.2 볼륨 매핑
| 호스트 경로 | 컨테이너 경로 | 용도 |
|-------------|---------------|------|
| .docker-data/mysql | /var/lib/mysql | MySQL 데이터 |
| .docker-data/redis | /data | Redis 데이터 |
| .docker-data/uploads | /app/uploads | 업로드 파일 |
| .docker-data/vector_store | /app/data/vector_store | Chroma 벡터 DB |

### 4.3 헬스체크
- MySQL: `mysqladmin ping -h localhost` (10초 간격, 5회 재시도)
- Redis: `redis-cli ping` (10초 간격, 5회 재시도)
- app: depends_on mysql(healthy) + redis(healthy)
- ai-engine: depends_on mysql(healthy)

## 5. 트러블슈팅

### 5.1 포트 충돌 (8080 already in use)
```bash
# 점유 프로세스 확인 및 종료
lsof -ti:8080 | xargs kill -9
# 이후 docker compose up -d
```

### 5.2 MySQL 인코딩 깨짐
- 증상: 한글이 `ê¹€í˜„ìˆ˜`로 표시
- 원인: 클라이언트 charset이 latin1
- 해결: docker-compose.yml에 `--skip-character-set-client-handshake` 확인

### 5.3 Hibernate DDL과 data.sql 충돌
- 증상: `Table doesn't exist` 에러
- 원인: data.sql이 Hibernate DDL보다 먼저 실행
- 해결: `defer-datasource-initialization: true` 설정 확인

### 5.4 AI 엔진 RAG 응답 없음
- 증상: "관련 문서 근거를 찾지 못했습니다" 고정 응답
- 원인: document_chunks 테이블 비어 있음 (벡터 미인덱싱)
- 해결: 프론트에서 문서 업로드 → AI 엔진이 자동 청킹/임베딩
- 확인: `SELECT COUNT(*) FROM document_chunks;`

### 5.5 Docker 이미지 캐시 문제
- 증상: 코드 변경이 Docker 컨테이너에 반영 안 됨
- 해결: `docker compose up -d --build app`으로 재빌드
